
# Bidirectional Cross‑Attention Multimodal Fusion for Glioma Subtyping and Grading

Source code for manuscript: **Bidirectional Cross‑Attention‑Based Multimodal Fusion of Histopathological and Multi‑Omics Features for Interpretable Glioma Subtyping and Grading**

> ⚠️ Important notice
> 1. This repository only contains source scripts. **Raw TCGA whole‑slide images, patch‑level h5 features, full individual‑level clinical/omics processed file are NOT distributed**, complying with TCGA data usage policy.
> 2. `data/imputed_data_template.csv` provides only column‑name template. Users shall download raw multi‑omics and clinical data from TCGA and preprocess following this template.
> 3. No pre‑computed result tables (enrichment outputs, attribution feature csv) or trained model checkpoints are provided in this repository. **All experimental outputs presented in the manuscript need to be reproduced locally by running the provided source code.**
> 4. All figures and tables in the manuscript can be regenerated by executing the scripts under `src/`.

## Environment
Please create conda environment from provided `env.yml`
```bash
conda env create -f env.yml
conda activate glioma‑multimodal
```
Additional dependencies (Mamba‑SSM, causal‑conv1d) shall be installed following their official project instructions.

## Workflow overview
The pipeline contains 4 major parts: **dataset splitting → model training → result visualization → biological interpretability analysis**.

### 1. Dataset splitting (patient‑level stratified split)
```bash
python src/dataset_split_patient.py
```
Set random seed inside script. Perform patient‑based stratified splitting according to glioma subtype and grade, generating train / validation / test split files stored under `data/`.

### 2. Model training
#### 2.1 Omics‑only model
```bash
python src/omics_feature_extract.py   # Omics feature pre‑processing & extraction
python src/omics_model.py             # Train omics‑only model
```

#### 2.2 WSI histopathology‑only model
```bash
python src/img_model_loader.py        # Data loader setup for whole‑slide image features
python src/train_img_model.py         # Train image‑only model
```

#### 2.3 Multimodal fusion model (core bidirectional cross‑attention model)
```bash
python src/multimodal_loader.py       # Multimodal dataloader
python src/train_multimodel.py       # Train multimodal fusion model
```

### 3. Result & performance visualization (ROC‑AUC)
Single‑seed ROC visualization:
```bash
# Multimodal model
python src/auc_cross.py
# Image‑only model
python src/auc_img.py
# Omics‑only model
python src/auc_omics.py
```

Multi‑seed aggregated ROC visualization (repeat experiments across multiple random seeds):
```bash
python src/auc_cross_seed.py
python src/auc_img_cross_seed.py
python src/auc_omics_cross_seed.py
```

#### Baseline model comparison (ROAM, Mamba‑MIL, CLAM)
```bash
# 3‑class classification: Astrocytoma / Oligodendroglioma / GBM
python src/auc_compared_3model.py

# 2‑class classification: Astrocytoma vs Oligodendroglioma (GBM merged into astrocytoma)
python src/auc_compared_4model.py
```

### 4. Attention map preview & visualization
> Note: Many WSIs produce scattered attention output; manual screening for representative slides is recommended.
```bash
python src/step1_preview_correct.py
# Preview thumbnails of correctly‑predicted slides under six‑class task for manual slide selection

python src/step2_final_grid.py
# Generate final attention heatmap grids for selected slides
```

### 5. Biological interpretability analysis (attribution & downstream analysis)
```bash
python src/global_explanation_pipeline.py
```
Run global gradient‑based attribution for four prediction tasks: subtype classification, astrocytoma grading, oligodendroglioma grading, six‑class fine‑grained diagnosis.
Output top‑ranked features: top200 expression genes, top60 SNV+CNV mutations, top100 methylation features for each tumor category.

#### Downstream analysis based on attribution outputs
1. Gene‑level heatmap visualization
```bash
python src/plot_heatmaps.py
```
> GO / KEGG enrichment analysis: Export top‑ranked gene lists and run **Multiple Gene Lists** analysis on Metascape web‑tool.

2. SNV & CNV mutation landscape plot
```bash
python src/SNV_CNV.py
```

3. Methylation‑expression correlation workflow
```bash
python src/compute_intersection.py      # Intersection analysis
python src/compute_correlation.py        # Correlation calculation
python src/omics_point_line_plane.py    # Scatter plots for strongest negative‑correlation pairs, output Cytoscape interaction files
```
> Gene sets derived from negative‑correlated methylation‑gene pairs can also be submitted to Metascape for enrichment analysis using Multiple Gene Lists mode.
